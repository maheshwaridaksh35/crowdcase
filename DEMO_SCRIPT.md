# CrowdCase — demo script (under three minutes)

Record the final demo only after the real Twitch-to-AI workflow and intended overlay have been tested. Do not narrate synthetic data as live output or a fallback as AI output.

## 0:00–0:15 — Hook
Show CrowdCase and say: "Livestream chat moves fast. CrowdCase turns viewers into a team solving a mystery."

## 0:15–0:35 — The case
Show The Midnight Gallery Heist, the evidence board, suspects and timeline.

## 0:35–1:00 — Real Twitch chat
Show the real channel and send a !theory message. Show that same message arriving in CrowdCase.

## 1:00–1:25 — AI case intelligence
Collect at least three genuine chat messages and click Analyze chat. Show the real AI result only if the UI reports AI ANALYSIS; otherwise clearly explain the fallback.

## 1:25–1:50 — Community interaction
Cast a valid !vote during an open round and reveal a clue. Do not claim votes or state are shared beyond the dashboard session unless verified.

## 1:50–2:15 — Overlay and Codex
Show OBS only if the overlay has actually been tested in OBS Browser Source. Show Codex implementing a meaningful feature and running tests/build.

## 2:15–2:45 — Close
Show the public repo and deployed app. End with: "CrowdCase makes the chat part of the story."

## Recording checklist
- Public YouTube video shorter than three minutes.
- Genuine Twitch chat shown.
- AI claims reflect the actual output.
- Actual Codex build footage shown.
- No tokens, Client Secrets, passwords or API keys visible.
- Repository and app links work; every claim is verifiable.
